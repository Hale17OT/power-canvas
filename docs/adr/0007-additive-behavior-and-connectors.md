# ADR 0007: Additive model-driven behavior and bounded connectors

Status: accepted, 18 September 2026.

New model-driven apps explicitly use Unified Interface client type 4. Conversion of an owned app from 2 to 4 is the sole allowed app property update in Default; identity, membership and unrelated properties must match. Draft Active layers require a separately verified published counterpart. Acknowledged writes and later observer failures are recovered through read-only evidence, never blindly replayed.

Reveal behavior can target optional existing ordinary columns only. Add a new deterministic JavaScript resource and append only missing form rows, library and handler. Unknown conflicting onload groups, libraries and handlers block the change. Use executionContext/PrimaryControl and supported Client APIs, never DOM access or hidden service calls. Modern command binding is currently created in Maker and independently read back; the CLI does not claim generalized appaction generation.

Connector generation starts with GET-only bounded Swagger 2 contracts. Secrets never enter the specification or generated artifacts. Real connection setup and OAuth credentials remain in Power Platform. Local fixtures cover protocol behavior; they do not prove external reachability, DLP compliance, licensing or delegated permissions. Collisions and unapproved/fixture hosts block deployment planning. PAC/Maker transport and authenticated live connection tests remain separate capabilities.
